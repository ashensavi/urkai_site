# URKAI Website — Product Catalogue Version

Static responsive website built with Tailwind CSS CDN.

## Pages
- `index.html` — Home
- `products.html` — Product catalogue with generated URKAI product visuals and draft specifications
- `about.html` — About
- `faq.html` — FAQ

## Product assets
Located in `assets/products/`:
- Hex Dumbbell Set
- Adjustable Bench
- Power Rack
- Olympic Weight Plates
- Functional Trainer
- Indoor Spin Bike

## Important before publishing
The product images are generated catalogue visuals, and the included specifications are draft/representative values created for the website concept. Verify actual model specifications, dimensions, load ratings, materials, warranty information and certifications against the real products before using them as final sales claims.

## Running locally
Open `index.html` in a browser. An internet connection is required for the Tailwind CDN and Google Fonts.
